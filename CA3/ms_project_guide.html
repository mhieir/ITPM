0پیش‌نیازها

نرم‌افزار Microsoft Project نسخه ۲۰۱۹ یا بالاتر (یا Project Professional/Online) را نصب کنید. این راهنما با مسیرهای رابط فارسی/انگلیسی نوشته شده و ساختار منوها در نسخه‌های اخیر تفاوت چندانی ندارد.

نکته: فایل XML همراه (project.xml) را می‌توانید مستقیماً از طریق File → Open → project.xml در MS Project باز کنید. این کار اکثر مراحل ۳ تا ۵ را به‌صورت خودکار انجام می‌دهد.

1تنظیم تقویم پروژه

چون مدت‌های پروژه به ماه داده شده‌اند و در محاسبه دستی همه ماه‌ها برابر در نظر گرفته شده، باید تقویمی بسازیم که در آن هر ماه دقیقاً ۲۰ روز کاری (یعنی ۴ هفته × ۵ روز کاری) یا به‌سادگی ۲۴/۷ باشد تا اعداد دستی با نرم‌افزار منطبق شوند.

1
ایجاد تقویم جدید با نام Sport-App Cal

منوی Project → Change Working Time → Create New Calendar را انتخاب کنید. گزینه Make a copy of Standard calendar را برگزینید و نام آن را Sport-App Cal بگذارید.

2
تنظیم کل هفته به‌صورت کاری ۲۴ ساعته

در پنجره باز شده، تب Work Weeks → دکمه Details. تمامی روزها (شنبه تا جمعه) را انتخاب کنید و گزینه Set day(s) to these specific working times را انتخاب کنید. ساعات را روی 00:00 – 24:00 تنظیم کنید (یا برای ساده‌تر شدن، فقط در تب Work Weeks تمام روزها را Working قرار دهید).

3
تنظیم Hours per day و Days per month

منوی File → Options → Schedule. مقادیر را به این صورت تنظیم کنید:
Hours per day = 8  ·  Hours per week = 56  ·  Days per month = 30
گزینه Default task type = Fixed Duration و New tasks are: Auto Scheduled را فعال کنید.

هشدار: اگر این مرحله را انجام ندهید، MS Project به‌طور پیش‌فرض تعطیلات آخر هفته را در نظر می‌گیرد و یک ماه ۳۰‌روزه را معادل حدود 22 روز کاری حساب می‌کند؛ در نتیجه تاریخ‌های شروع/پایان با محاسبه دستی شما اختلاف خواهند داشت (هرچند مقادیر Slack بر حسب «ماه» باز هم مطابق خواهند ماند، تاریخ‌های تقویمی متفاوت می‌شوند).

4برقراری وابستگی‌ها

ساده‌ترین راه: مقادیر ستون Predecessors جدول بالا را تایپ کنید. راه جایگزین: دو فعالیت را در نمای Gantt انتخاب کنید و کلیدهای Ctrl + F2 یا دکمه Link Tasks از تب Task را بزنید.

پس از پایان، نوع همه روابط را در Task → Information → Predecessors tab چک کنید که Finish-to-Start (FS) و Lag = 0 باشند.

5افزودن ستون‌های Slack

1
سوییچ به نمای Detail Gantt

منوی View → More Views → Detail Gantt → Apply. این نما به‌طور خودکار میله‌های Slack را روی نمودار Gantt نمایش می‌دهد.

2
افزودن ستون‌های Free Slack و Total Slack

روی Header یکی از ستون‌ها راست‌کلیک کنید و Insert Column را بزنید. ستون‌های زیر را اضافه کنید:

  1. Early Start
  2. Early Finish
  3. Late Start
  4. Late Finish
  5. Free Slack
  6. Total Slack
  7. Critical (مقدار Yes/No)

6گرفتن نمودار PDM (Network Diagram)

منوی View → Network Diagram. نمودار شبکه‌ای فعالیت‌ها نمایش داده می‌شود. برای نمایش بهتر:

  1. روی نمودار راست‌کلیک → Layout → چینش خودکار را فعال کنید.
  2. روی هر گره راست‌کلیک → Box Styles → از قالب «Standard» یا «Critical» استفاده کنید.
  3. برای دیدن ES/EF/LS/LF داخل کادر هر فعالیت: Format → Box Styles → More Templates → Edit و فیلدهای موردنظر را اضافه کنید.

7اسکرین‌شات‌های لازم

طبق فایل صورت تمرین، حتماً سه نوع اسکرین‌شات برای پیوست به گزارش بگیرید:

  1. نمای Gantt با ستون‌های افزوده ES/EF/LS/LF/Free Slack/Total Slack/Critical. کلید: PrtScn یا ابزار Snipping Tool.
  2. Network Diagram (PDM) با مسیر بحرانی هایلایت‌شده. کلید: View → Network Diagram سپس از کل صفحه عکس بگیرید.
  3. Task Sheet (یا همان جدول ساده) با ستون Critical فعال — برای نشان دادن کدام فعالیت‌ها بحرانی هستند.
